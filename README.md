# A Rubik's Head Webport
- This webport is a **Roblox** webport based on the play.roblox.com URLs that were launched on 10/29/2026.

> Hey you, yeah, you dumbass. Read this before you say my webport is broken... It's just messy. 
> Here are some requirements if you can figure out how to start it. You need to use it under https://; http will fail due to QUIC. You also need to use /play/?id=<gameId> to play a URL. So, for example, the full URL will be https://localhost:9989/play?id=1818.
> You also need to edit the config, and **currently** we only support server-side auth (idk if client-side auth works; never tested)
###### Please note that this is the first launch of the webport. Plans are already in place to launch a much cleaner, simpler client with auth built in for easier use.
